# Phrase bank

Phrasings that read as written by a person. Transliterations are for choosing between options,
not for output — never send transliterated Hebrew.

## Greetings

| Hebrew | Translit | When |
|---|---|---|
| `שלום` | Shalom | Any time, any register |
| `היי` | Hai | Casual, the default in chat |
| `אהלן` | Ahlan | Casual, warm |
| `בוקר טוב` / `צהריים טובים` / `ערב טוב` | Boker tov / Tsohorayim tovim / Erev tov | By the clock — see `formats.md` |
| `איך אפשר לעזור?` | Eikh efshar la'azor? | Opening line, impersonal |
| `במה אוכל לסייע?` | Ba'ma ukhal lesaye'a? | Formal only |

## Acknowledging

| Hebrew | Translit | When |
|---|---|---|
| `הבנתי` | Hevanti | Got it — genderless, use this |
| `קיבלתי` | Kibalti | Received it, handling it |
| `מעולה` | Me'ule | Good, that works |
| `סבבה` | Sababa | Casual OK |
| `בסדר גמור` | Be'seder gamur | Fine, no problem |
| `נרשם` | Nirsham | Noted / logged |
| `בוצע` | Butza | Done |

## Working on it

| Hebrew | Translit | When |
|---|---|---|
| `רגע, בודקת` → prefer `רגע, אני על זה` | Rega, ani al ze | Present-tense verbs gender you; this doesn't |
| `עוד רגע` | Od rega | Just a moment |
| `שולח עכשיו` → prefer `נשלח` | Nishlakh | Passive avoids self-gendering |
| `בדקתי, ו...` | Badakti | Past tense, genderless, leads into the answer |

## Errors and not understanding

| Hebrew | Translit | When |
|---|---|---|
| `לא הצלחתי` | Lo hitzlakhti | Plain failure, genderless |
| `לא הבנתי` | Lo hevanti | Didn't follow |
| `אפשר לנסח אחרת?` | Efshar lenase'akh akheret? | Ask for a rephrase |
| `משהו נשבר` | Mashehu nishbar | Something broke |
| `זה לא עבד` | Ze lo avad | It didn't work |
| `סליחה על העיכוב` | Slikha al ha'ikuv | Sorry for the delay |
| `נסו שוב` | Nasu shuv | Try again — plural, safe |

## Asking

| Hebrew | Translit | When |
|---|---|---|
| `אפשר לאשר?` | Efshar le'asher? | Confirm? — impersonal |
| `לאשר או לבטל?` | Le'asher o levatel? | Binary choice, no pronoun |
| `יש לשלוח תמונה ברורה יותר` | Yesh lishlo'akh… | Needs X — impersonal imperative |
| `תשלחו לי את המספר` | Tishlekhu… | Plural imperative, safe for anyone |
| `מה השם?` | Ma ha'shem? | Drop `שלך` and the gender goes with it |
| `באיזו עיר?` | Be'eizo ir? | Same trick |
