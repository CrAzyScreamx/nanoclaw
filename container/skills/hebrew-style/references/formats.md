# Israeli formats

| Thing | Israeli form | Not |
|---|---|---|
| Date | `14/03/2026` or `14.3.2026` | `2026-03-14`, `03/14/2026` |
| Date in prose | `יום שלישי, 14 במרץ` | `מרץ 14` |
| Time | `14:30`, `בשעה 9:00` | `2:30 PM` |
| Time range | `9:00–17:00` | `9am–5pm` |
| Currency in prose | `50 ש"ח` | `50 - ₪`, `NIS 50`, `50 shekels` |
| Currency as a label | `₪50` | — |
| Thousands | `1,200` | `1.200`, `1 200` |
| Decimals | `12.5` | `12,5` |
| Mobile | `050-1234567` | `+972 50 123 4567` in casual Hebrew prose |
| Landline | `02-1234567` | — |
| Percent | `15%` | `אחוז 15` |

`50 ש"ח` is the safest money form in a chat line: every character is a Hebrew letter, so there is
no direction to get wrong. `₪` is directionally neutral and can drift, so keep it adjacent to its
digits (`₪50`) or use `ש"ח` instead.

## The week

`א'` Sunday · `ב'` Monday · `ג'` Tuesday · `ד'` Wednesday · `ה'` Thursday · `ו'` Friday ·
`שבת` Saturday.

`א'–ה'` is the work week. `ו'` is a short day — most places close early afternoon. `שבת` is
closed. Sunday is a normal work day; never treat it as weekend.

## Greetings by clock and calendar

| When | Greeting |
|---|---|
| Morning until noon | `בוקר טוב` |
| Around midday | `צהריים טובים` |
| Evening | `ערב טוב` |
| As a goodbye at night | `לילה טוב` (not a greeting) |
| Any time | `שלום`, `היי`, `אהלן` |
| Thursday evening onward | `שבת שלום` |
| Saturday night through Sunday | `שבוע טוב` |
| Around a holiday | `חג שמח` |

Using one greeting all day long is a tell.

## Relative time

`עכשיו` · `לפני {n} דקות` · `לפני {n} שעות` · `אתמול` · `שלשום` · `לפני {n} ימים` · `היום` ·
`מחר` · `מחרתיים` · `בעוד שעה` · `בשבוע הבא`

## Abbreviations

Gershayim — a double quote before the last letter — for a multi-word abbreviation:
`ת"ז` (ID) · `ש"ח` (shekels) · `ק"ג` · `ד"ר` · `בע"מ` · `בס"ד` · `אח"כ`

Single geresh for a shortened single word: `טל'` (phone) · `ד'` · `וכו'`

Straight `"` and `'` are what everyone types. The typographic `״` and `׳` are optional and worth
using only in something typeset.
