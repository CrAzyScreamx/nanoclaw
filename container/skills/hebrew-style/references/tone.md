# Register, tone, and not-translated-from-English

## Register

**Default to informal — דוגרי.** Direct, short, no ceremony. Formal Hebrew in a chat reads as
robotic and puts distance between you and the person, which is the opposite of what an assistant
wants. Formal register is right for government, banking, legal, and anything a lawyer will read.

Informal: second person singular or impersonal, short sentences, `אין בעיה`, `סבבה`, `יאללה`.
Formal: full sentences, passive or impersonal throughout, `כיצד נוכל לסייע`, `נא להמתין`.

## Cut the softeners

Israeli chat reads padding as evasion.

| Not this | This |
|---|---|
| `ייתכן שכדאי לשקול לשלוח תמונה נוספת` | `לא הצלחתי לקרוא את הקבלה, תשלחו תמונה ברורה יותר` |
| `נשמח אם תוכל/י לאשר` | `אפשר לאשר?` |
| `אנחנו מתנצלים על אי הנוחות` | `סליחה על העיכוב` |
| `שאלה מעולה!` | *(delete the line)* |
| `אני כאן כדי לעזור לך בכל שאלה` | *(delete the line)* |

`תודה` and `סליחה` still belong. This is about refusing to spend a line on nothing, not about
being brusque.

## Length

A chat message is a message, not a document. One answer, one confirmation, one question. No
preamble, no recap of what you just did, no summary of a list you just sent. If the reply needs
headings, it probably isn't a chat reply.

## Emoji

Fine in casual conversation, one at most, at the end of the line. Never mid-line in something you
had to bidi-mark — an emoji is directionally neutral and will shift a nearby number. Skip them
entirely in anything formal.

## Not translated from English

| Literal (wrong) | Natural |
|---|---|
| `כיצד אני יכול לעזור לך?` | `איך אפשר לעזור?` |
| `בסוף היום` (meaning "ultimately") | `בסופו של דבר` |
| `אני מצטער לשמוע את זה` | `סליחה על זה` / `לא נעים` |
| `בבקשה תן לי לדעת` | `תעדכנו` / `תגידו לי` |
| `אני אבדוק את זה ואחזור אליך` | `אבדוק ואחזור` |
| `יש לך יום נהדר!` | `שיהיה יום טוב` |
| `בוא נעשה את זה` | `יאללה` / `קדימה` |
| `זה נשמע טוב` (as agreement) | `מעולה` / `סבבה` |
| `תודה על הסבלנות שלך` | `תודה על ההמתנה` |
| `האם אתה בטוח?` | `בטוח?` / `לאשר?` |

Don't translate a product or feature name into Hebrew unless there's an established Hebrew name.
Brand names, CLI verbs, and file names stay Latin — just close them with `‏` (rendering rule 3).
